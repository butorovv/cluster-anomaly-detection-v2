# Контракт GUI и Master

Базовый коммит разработки — 782d401878761639baae3f186351bb0802aa5b4d (проверенная вершина origin/main).

| GET | Фактический контракт |
| --- | --- |
| /healthz | HTTP 200 от Master |
| /readyz | HTTP 200 при успешном SQL ping, иначе 503 |
| /v1/summary | execution_id, идентификаторы, ожидаемые и записанные групповые тики, счётчики решений и завершённых событий. complete означает совпадение количества групповых тиков с ожидаемым |
| /v1/results | execution_id, limit 1–128, after_tick и after_group. Ответ {items,next}, items содержат raw, temporal, evidence. Сервер также ограничивает суммарный объём страницы, поэтому короткая страница может иметь продолжение |
| /v1/events | execution_id, необязательная группа, limit 1–500, after. Ответ — массив терминальных RBI2Event, отсортированных по id |
| /metrics | JSON со временем снимка, labels, counters, gauges, histograms и process. Доступность показателей зависит от конфигурации и платформы |

В SQL неизменяемые результаты упорядочены по (tick, group_id). Запись с меньшим ключом может стать видна после чтения страницы. У событий аналогичный риск: event_id — хеш, а не время публикации. Завершённое событие неизменно. Для обоих потоков клиент сверяет количество уникальных ключей с отдельным снимком сводки, снятым до чтения страниц. При отставании перечитывает результаты после подтверждённой непрерывной границы, события — с начала. Если обнаружение пропуска произошло во время обхода, следующая сводка запускает новую сверку.

Дополнительные поля summary описывают зарегистрированную топологию и границы окна, а также первый и последний зарегистрированные моменты приёма групповых результатов. Сетка имеет шаг 10 секунд, а группы регистрируются в диапазоне a01…aNN. Моменты приёма относятся к системному времени PostgreSQL; это опорные точки для интервала приёма Master. Replayer измеряется отдельно в демонстрационном сценарии.

Raw содержит исходные R/B, число полных наблюдений, список отсутствующих узлов и локальный Isolation Forest. Локальный I2, временные R/B/I2, итог и активные голоса берутся из temporal. Evidence может отсутствовать; его event_id и witness_refs описывают свидетельства Backend. AnnotateOutside предоставляет число доступных и аномальных IF-результатов за пределами текущей группы, список других групп, долю outside_s и разность e = s − outside_s, если обе доли определены. Значение null сохраняет смысл «нет данных».

Master не подтверждает тип источника и скорость Replayer. Для демонстрации эти сведения передаются GUI при запуске из проверенной конфигурации сценария; ручной ввод другого execution_id сбрасывает их. Управление темпом происходит через существующий --speed в Replayer. Для full-grid сроки тиков рассчитываются по времени телеметрии: 1, 5, 10 и 0 соответствуют 10 с, 2 с, 1 с и отключённой задержке.
